# Smart Trip Planner

A college-level integrated web and mobile application for planning trips based on destination, budget, travel dates, number of people, and preferences.

## Technology Stack

- React
- Kotlin
- Spring Boot
- MySQL
- JPA/Hibernate
- JWT
- Flutter
- Firebase
- Git/GitHub
- Postman

## Main Features

- Trip Planning
- Budget Rebalancer
- Smart Day Routing
- Transport and Stay Options
- Day-wise Itinerary
- React Web Application
- Flutter Mobile Application
